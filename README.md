# CruiseMind
### ИИ-консьерж для речных круизов по Золотому кольцу России

## Структура проекта

Проект разделён на три основные части: дизайн, документация и серверная часть.


## Идея проекта

CruiseMind — мобильное приложение с ИИ-ассистентом, которое объединяет разрозненную информацию на круизном судне в единую точку доступа.

В настоящее время расписание мероприятий, прогноз погоды, заявки на уборку и сигналы тревоги могут поступать через разные каналы: бумажные брошюры, объявления по громкой связи и личные сообщения.

Это затрудняет получение информации пассажирами, обработку заявок сотрудниками и своевременное реагирование администрации на тревожные сигналы.

CruiseMind решает эту проблему, предоставляя единое цифровое пространство с учётом ролей пользователей и QR-авторизацией.

## Основные роли пользователей

- **Пассажир** — получает рекомендации «что делать прямо сейчас»: расписание мероприятий с выделением текущих событий, информацию о городах Золотого кольца и погоду в текущей точке маршрута.
- **Горничная** — просматривает заявки на уборку с возможностью фильтрации по палубам.
- **Капитан / администратор** — получает сигналы тревоги (SOS) и звуковые оповещения.

## API — серверная часть

Серверная часть разработана на **C# с использованием ASP.NET Core 8.0** и размещена на хостинге MonsterASP.

API обеспечивает взаимодействие мобильного приложения с базой данных и внешними сервисами.

**Swagger:** [Открыть документацию API](http://shipapi.runasp.net/swagger)

### Основные возможности API

- **Авторизация** — выдача JWT-токенов для доступа к защищённым методам (роль ADMIN).
- **Расписание (CRUD)** — получение расписания на текущий день, создание, редактирование и удаление мероприятий.
- **Каюты и уборка** — получение списка кают с фильтрацией по палубам и пагинацией для горничных.
- **Система тревог (SOS)** — получение списка активных тревожных сигналов для капитана.
- **ИИ-консьерж** — интеграция с GigaChat. Принимает историю сообщений и контекст (текущий город, погода) и формирует ответ.
- **Погода** — интеграция с OpenWeatherMap для получения актуальной температуры и влажности по названию города.

### Безопасность

В серверной части реализованы:

- **JWT-аутентификация** — защита API-методов.
- **CORS** — управление доступом к API со стороны других приложений.
- **Rate Limiting** — ограничение частоты запросов для защиты от чрезмерной нагрузки.
- **Логирование ошибок** — упрощение диагностики и сопровождения приложения.
