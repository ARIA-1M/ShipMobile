# CruiseMind

**ИИ-консьерж для речных круизов по Золотому кольцу России**

## Идея

CruiseMind — мобильное приложение с ИИ-ассистентом, которое объединяет
разрозненную информацию на круизном судне в единую точку доступа.

На борту расписание мероприятий, погода, заявки на уборку и сигналы
тревог сейчас разбросаны по бумажным брошюрам, объявлениям по громкой
связи и личным сообщениям. Пассажиры пропускают интересные события,
сотрудники задерживаются с обслуживанием кают, а администратор медленно
реагирует на тревоги.

CruiseMind решает это через три ролевых сценария с QR-авторизацией:

- **Пассажир** — получает контекстные рекомендации «что делать прямо
  сейчас»: расписание дня с подсветкой текущих мероприятий, карточки
  городов Золотого кольца, погоду в текущей точке маршрута.
- **Горничная** — видит заявки на уборку с фильтром по палубам.
- **Капитан / администратор** — получает сигналы тревог со звуковым
  оповещением.
